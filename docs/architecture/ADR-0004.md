# ADR-0004: Extensiones aisladas, declarativas y gobernadas por permisos

## Estado

Aceptado.

## Problema

Las extensiones de terceros necesitan extensibilidad sin acceso implícito a secretos, archivos, red o procesos.

## Alternativas consideradas

1. Plugins ejecutados libremente en el proceso principal.
2. APIs internas sin manifiestos ni control de versión.
3. Extension API pública, Extension Host y manifiestos con permisos explícitos.

## Decisión

Las extensiones usarán `@piston/extension-api` y se cargarán mediante `@piston/extension-host`. El manifiesto declarará versión, capacidades requeridas, permisos, dependencias y ubicación de ejecución. El control plane aplicará las decisiones de política.

## Consecuencias

La primera implementación puede ser local, pero el contrato permite aislamiento posterior en workers o procesos. Las extensiones no pueden importar internals de Piston ni otras extensiones directamente.
