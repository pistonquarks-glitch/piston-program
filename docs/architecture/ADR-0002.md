# ADR-0002: Separación entre clientes, control plane y agent worker

## Estado

Aceptado.

## Problema

Un agente de larga duración no debe bloquear una interfaz ni perder su sesión cuando un cliente se cierra.

## Alternativas consideradas

1. Ejecutar agentes dentro de cada cliente.
2. Ejecutar todo en un proceso monolítico.
3. Separar clientes, control plane y workers de agentes.

## Decisión

Los clientes observan y controlan sesiones; el control plane coordina sesiones, políticas, registros y eventos; el agent worker ejecutará agentes. Las fronteras se definen desde la Fase 1 aunque la implementación distribuida se difiere.

## Consecuencias

El sistema puede empezar localmente y evolucionar a un daemon o servicio remoto sin cambiar los contratos públicos. Ningún cliente importará la implementación del control plane.
